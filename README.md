# 简单的待办事项列表 (Simple Todo List)

这是一个使用原生 HTML、CSS 和 JavaScript 构建的轻量级待办事项管理应用。它支持中文字符，并具备深色模式切换功能。

## 功能特点

- **添加任务**：输入文字后点击“添加”按钮或按回车键即可将任务加入列表。
- **删除任务**：点击每个任务旁边的“删除”按钮可将其从列表中移除。
- **主题切换**：支持浅色和深色（夜间）模式，并自动保存您的主题偏好。
- **响应式设计**：适配不同尺寸的屏幕。
- **持久化主题**：使用 `localStorage` 保存您的主题设置，下次访问时自动加载。

## 技术栈

- **HTML5**：页面结构。
- **CSS3**：使用 CSS 变量（Variables）实现动态主题切换。
- **JavaScript**：实现交互逻辑及本地存储。

## 如何运行

本项目不依赖任何外部库或构建工具，直接在浏览器中打开 `index.html` 即可运行：

1. 克隆或下载此仓库。
2. 导航到项目根目录。
3. 双击 `index.html` 或将其拖入您的浏览器中。

## 文件结构

- `index.html` - 页面的主要 HTML 结构。
- `style.css` - 包含布局样式和主题（浅色/深色）定义。
- `script.js` - 实现添加、删除任务及主题切换的 JavaScript 代码。

## 预览

应用界面采用现代风格设计，具有柔和的阴影和圆角。深色模式可以有效减轻在暗光环境下的视觉疲劳。
